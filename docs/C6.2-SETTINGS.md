# C6.2 — Platforma sozlamalari

## Endpointlar

- `GET /api/v1/admin/settings` — `ADMIN` va `SUPERADMIN`.
- `PUT /api/v1/admin/settings` — faqat `SUPERADMIN`.

`PUT` to'liq body qabul qiladi:

```json
{
  "commissionPercent": 7.5,
  "minimumOrderAmount": 50000,
  "supportPhone": "+998712000000"
}
```

Komissiya `0..100`, minimal summa `0` yoki undan katta bo'lishi kerak. Telefon bo'sh satr yoki `+998XXXXXXXXX` formatida bo'ladi. O'zgarish va audit yozuvi bitta DB tranzaksiyasida saqlanadi; audit action — `platform.settings.update`.

Checkout har yangi buyurtmada `minimumOrderAmount`ni, admin dashboard esa daromad hisobida `commissionPercent`ni identity servisidan qayta o'qiydi. Shu sababli qiymatni o'zgartirish servislarni qayta ishga tushirmasdan keyingi so'rovdayoq ishlaydi.

## Qo'lda tekshirish

```bash
curl -H "Authorization: Bearer $SUPERADMIN_TOKEN" \
  http://localhost:3000/api/v1/admin/settings

curl -X PUT \
  -H "Authorization: Bearer $SUPERADMIN_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"commissionPercent":7.5,"minimumOrderAmount":50000,"supportPhone":"+998712000000"}' \
  http://localhost:3000/api/v1/admin/settings
```

Update'dan keyingi `GET` yangi qiymatlarni qaytarishi kerak. `commissionPercent: 101` uchun `400`, oddiy `ADMIN_TOKEN` bilan `PUT` uchun `403` qaytishi kerak. Auditni quyidagicha tekshirish mumkin:

```bash
curl -H "Authorization: Bearer $SUPERADMIN_TOKEN" \
  "http://localhost:3000/api/v1/admin/audit?action=platform.settings.update"
```
