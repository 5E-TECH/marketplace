# C6.5 — Foydalanuvchi roli va nomidan kirish

## Endpointlar

### Rolni o‘zgartirish

```http
PATCH /api/v1/admin/users/:id/role
Authorization: Bearer <SUPERADMIN access token>
Content-Type: application/json

{ "role": "SELLER" }
```

Ruxsat etilgan rollar: `BUYER`, `SELLER`, `ADMIN`, `SUPERADMIN`.
`OPERATOR` bu endpoint orqali berilmaydi, chunki unga majburiy `shopId` scope
kerak va u seller operatorlari oqimi orqali boshqariladi.

Rol o‘zgarganda foydalanuvchining `authVersion` qiymati oshiriladi va barcha
faol refresh sessiyalari bekor qilinadi. Gateway har `@Roles` endpointida JWT
ichidagi rol va `authVersion`ni identity-service'dagi joriy qiymatlar bilan
tekshiradi. Shuning uchun eski access token muddati tugashini kutmasdan darhol
`401` oladi. O‘zgarish oldingi/yangi qiymat va IP bilan `user.role.update`
audit yozuviga atomar saqlanadi. Oxirgi faol `SUPERADMIN`ni pasaytirish `409`
bilan rad etiladi.

Deploydagi migratsiya mavjud userlarga `authVersion=1` beradi. Eski tokenlarda
bu claim bo‘lmagani uchun deploydan keyin ular qayta login qilishi kerak.

### Foydalanuvchi nomidan kirish

```http
POST /api/v1/admin/users/:id/impersonate
Authorization: Bearer <SUPERADMIN access token>
```

Javobdagi `impersonationToken`:

- faqat 15 daqiqa amal qiladi (`expiresIn: 900`);
- refresh token yoki server sessiyasini yaratmaydi;
- target userning `sub`, `role`, `shopId` claimlarini oladi;
- `impersonatedBy` va `tokenType: "impersonation"` claimlarini saqlaydi;
- `user.impersonate` audit yozuvini yaratmasdan qaytarilmaydi.

Faqat faol, bloklanmagan `BUYER`, `SELLER` yoki `OPERATOR` nomidan kirish
mumkin. `ADMIN`/`SUPERADMIN` akkauntlarini impersonate qilish va o‘z nomidan
qayta kirish bloklangan. Impersonation rejimida parolni o‘zgartirish ham
taqiqlangan.

## Qabul mezonlari

- TC1: rol o‘zgaradi; eski access va refresh tokenlar darhol bekor qilinadi;
  yangi rol huquqlari yangi login/token bilan ishlaydi; audit yoziladi.
- TC2: impersonation token target user huquqlari bilan ishlaydi.
- TC3: token 15 daqiqadan keyin yaroqsiz.
- TC4: har impersonation actor, target, muddat va IP bilan auditga tushadi.
- TC5: oddiy `ADMIN` ikkala endpoint uchun ham `403` oladi.
