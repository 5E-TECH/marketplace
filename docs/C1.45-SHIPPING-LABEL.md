# C1.45 — Buyurtma shipment yorlig‘i

## Endpoint

```http
GET /api/v1/seller/orders/:id/label
Authorization: Bearer <SELLER_OR_OPERATOR_TOKEN>
```

Bir nechta yorliq uchun:

```http
POST /api/v1/seller/orders/labels
Authorization: Bearer <SELLER_OR_OPERATOR_TOKEN>
Content-Type: application/json

{ "orderIds": ["101", "102"] }
```

Admin endpointlari: `GET /api/v1/admin/orders/:id/label` va
`POST /api/v1/admin/orders/labels`. Batch so‘rov 1–100 ta yorliqni har biri
100x60 mm bo‘lgan alohida PDF sahifalarda qaytaradi.

Javob `application/pdf`, `Content-Disposition: attachment`. Fayl 100x60 mm
termal printer formatida yaratiladi.

Yorliqda:

- Elchi shipment ID;
- marketplace va seller-order ID;
- qabul qiluvchi ismi, telefon va manzil;
- mahsulot nomlari va miqdori;
- COD olinadigan summa;
- Elchi `qr_code_token` qiymatidan yaratilgan QR mavjud.

## Xavfsizlik va holatlar

- SELLER faqat o‘z do‘koni buyurtmasini oladi.
- OPERATOR faqat JWT ichidagi `shopId` doirasida oladi.
- Begona yoki mavjud bo‘lmagan buyurtma `404`.
- Elchi shipment hali yaratilmagan yoki QR token yo‘q bo‘lsa `409`.
- QR token shipment yaratishda Elchi javobidan olinib
  `checkout.sales_order_seller.qr_code_token` maydonida saqlanadi.
- Elchi skanerdan `received` webhook yuborganda seller-order `RECEIVED`
  holatiga o‘tadi va tarixga yoziladi.
