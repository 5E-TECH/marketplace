# C6.1 — Admin jamoasini boshqarish

Faqat `SUPERADMIN` quyidagi endpointlardan foydalana oladi:

- `GET /api/v1/admin/team`
- `POST /api/v1/admin/team`
- `PATCH /api/v1/admin/team/:id/role`
- `DELETE /api/v1/admin/team/:id`

Yangi a'zo uchun `name`, `phone`, `role` va ixtiyoriy `password` yuboriladi. `password` berilmasa, javobda faqat bir marta ko'rsatiladigan `temporaryPassword` qaytadi. Ruxsatli rollar: `ADMIN`, `SUPERADMIN`.

Rol o'zgartirilganda yoki a'zo o'chirilganda uning faol refresh sessiyalari bekor qilinadi. Oxirgi faol SUPERADMINni pasaytirish yoki o'chirish `409` bilan rad etiladi. Create, role update va delete amallari oldingi/yangi qiymat hamda IP bilan audit jurnaliga atomar yoziladi.
