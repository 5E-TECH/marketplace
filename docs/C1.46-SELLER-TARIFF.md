# C1.46 — Sotuvchi tarifini Elchi provisioningga yuborish

## API

Admin Elchi market yaratilishidan oldin do‘kon tariflarini sozlaydi:

```http
PATCH /api/v1/admin/shops/:id/tariffs
Authorization: Bearer <ADMIN yoki SUPERADMIN token>
Content-Type: application/json

{
  "tariffHome": 25000,
  "tariffCenter": 15000
}
```

- `tariffHome` — mijoz uy manziliga yetkazish tarifi.
- `tariffCenter` — Elchi markaziga yetkazish tarifi.
- Ikkala qiymat ham `0` dan katta, ko‘pi bilan 2 kasr xonali.
- Yangi do‘kon uchun standart tariflar `25000` (uy) va `15000` (markaz).
- Elchi market oldin yaratilgan bo‘lsa, o‘sha market tarifi ham yangilanadi.

Oldin provision qilingan barcha marketlarni catalogdagi joriy tariflar bilan
qayta sinxronlash:

```http
POST /api/v1/admin/integration/markets/sync-tariffs
Authorization: Bearer <ADMIN yoki SUPERADMIN token>
```

Javob: `{ "total": 7, "updated": 7, "failed": 0 }`. Amal auditga yoziladi.
Xato marketlar `failed` holatiga o‘tadi va 30 soniyalik retry cron ularni yana
urinadi. Bundan tashqari integration service syncni har kuni 02:30 da avtomatik
bajaradi.

## Uyga va markazga yetkazish

`POST /api/v1/checkout/delivery-preview` va `POST /api/v1/checkout` ichidagi
`address` obyektida quyidagi maydon qabul qilinadi:

```json
{
  "whereDeliver": "ADDRESS"
}
```

- `ADDRESS` — `tariff_home`; Elchiga `where_deliver=address` yuboriladi.
- `CENTER` — `tariff_center`; Elchiga `where_deliver=center` yuboriladi.
- Maydon yuborilmasa backward compatibility uchun `ADDRESS` ishlatiladi.
- Tanlov `checkout.sales_order.where_deliver` ustunida saqlanadi va keyinchalik
  posilka yaratishda ham shu qiymat ishlatiladi.

## Provisioning oqimi

Do‘kon approve qilinganda `shop.approved` eventi hudud va ikkala tarifni olib
boradi. Integration service ularni `elchi_market_provision` jadvaliga snapshot
qiladi va Elchi so‘rovini quyidagi maydonlar bilan yuboradi:

```json
{
  "external_seller_id": "9",
  "name": "Zamon Store",
  "phone": "+998901234567",
  "region_id": "1",
  "district_id": "10",
  "tariff_home": 25000,
  "tariff_center": 15000
}
```

Elchi vaqtincha ishlamasa, retry aynan snapshotdagi hudud va tariflarni qayta
yuboradi. Shu sabab keyingi urinishda tariflar `0` ga tushib qolmaydi.
