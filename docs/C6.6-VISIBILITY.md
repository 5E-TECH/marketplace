# C6.6 — Do‘kon va mahsulot ko‘rinishini boshqarish

## Bog‘liqliklar

C6.6 ketma-ket C6.5 ga bog‘liq emas. Uni bajarish uchun quyidagi mavjud
imkoniyatlar kerak:

- C0.6 — katalog entity va migration infratuzilmasi;
- C1.32 — admin do‘kon moderatsiyasi;
- C4.5 — mahsulot `isBlocked` moderatsiyasi va search indeksidan chiqarish;
- C1.17 — sellerga notification yuborish;
- C1.31/C6.3 — admin amallarini audit jurnaliga yozish va ko‘rish;
- public storefront va search indeksatsiyasi.

Bu bog‘liqliklarning barchasi mavjud, shuning uchun C6.6 ni hozir bajarish
mumkin.

## API

### `POST /api/v1/admin/shops/:id/feature`

ADMIN yoki SUPERADMIN. Body:

```json
{ "featured": true }
```

`true` faqat ACTIVE do‘kon uchun qabul qilinadi. `false` do‘konni bosh sahifa
tavsiyalaridan olib tashlaydi. Amal `shop.feature.update` nomi bilan auditga
yoziladi.

### `GET /api/v1/storefront/shops/featured`

Public endpoint. Faqat ACTIVE, o‘chirilmagan va `isFeatured=true` do‘konlarni
rating bo‘yicha qaytaradi.

### `POST /api/v1/admin/products/:id/hide`

ADMIN yoki SUPERADMIN. Body:

```json
{ "reason": "Mahsulot rasmi qoidalarga zid" }
```

Mahsulot `isBlocked=true` bo‘ladi. Storefront query allaqachon bloklangan
mahsulotlarni filtrlab tashlaydi; `catalog.product.changed` hodisasi
`active=false` bilan search indeksidan ham o‘chiradi. `product.hidden` hodisasi
sotuvchiga sabab bilan in-app notification yaratadi. Amal `product.hide` nomi
bilan auditga yoziladi.

Mahsulotni qayta ko‘rsatish uchun mavjud
`POST /api/v1/admin/products/:id/reactivate` endpointi ishlatiladi.

## Acceptance mezonlari

- TC1: yashirilgan mahsulot storefront queryda `is_blocked = FALSE` filtri
  sabab ko‘rinmaydi;
- TC2: hide `active=false` search hodisasini yuboradi;
- TC3: featured belgisini qo‘yish va olish mumkin, public featured endpoint
  faqat faol featured do‘konlarni qaytaradi;
- TC4: sellerga mahsulot nomi va sabab bilan `product_hidden` xabari yaratiladi.
